# 🌀 Obstacle Assault

**Obstacle Assault** is a 3D third-person platformer game built with **Unreal Engine 5**. Players must navigate through a series of moving obstacles, jump across platforms, and time their movements precisely to reach the goal!

## 🎮 Gameplay Overview

- Navigate a challenging obstacle course in a **third-person perspective**.
- **Moving platforms, swinging objects, and rotating barriers** require timing and precision.
- Reach the end of the course without falling to complete the level.
- Character movement feels smooth and responsive, supported by full animation integration.

---

## 🧩 Features

- 🧍‍♂️ **Fully animated character** with blend spaces and animation blueprints.
- 🔄 **Dynamic moving obstacles** designed with Unreal Engine's Blueprint system and C++.
- 🎮 **Responsive third-person controls** for smooth and immersive gameplay.
- 🧠 Designed to challenge reflexes, timing, and platforming skills.

---

## 🛠️ Technologies Used

- Unreal Engine 5
- C++ (Core gameplay logic)
- Blueprints (Animation and movement logic)
- Animation Blueprints & Blend Spaces
- 3D Environment Design
- Third-Person Character Controller
